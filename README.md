# Student Details Program

A simple Python program that stores and prints basic student information, including the student's **name, roll number, and marks**.

## 📌 Project Description

`structstudent.py` is a beginner-friendly Python program designed to demonstrate how student details can be stored and displayed using Python. It prints the student's name, roll number, and marks in a clear format.

## ✨ Features

* Displays the student's name.
* Displays the student's roll number.
* Displays the student's marks.
* Simple and easy-to-understand Python code.
* Suitable for beginners learning Python.

## 📋 Requirements

* Python 3.x
* No external libraries or dependencies are required.

## 💡 Example

### Input

The program uses student details already defined in the Python file.

### Output

```text
Name: Rahul
Roll: 101
Marks: 87.5
```

> **Note:** The displayed values depend on the student details defined in `structstudent.py`.
